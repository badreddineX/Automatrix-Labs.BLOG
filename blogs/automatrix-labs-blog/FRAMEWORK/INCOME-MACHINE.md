## PART 2 — CONTENT STRUCTURE (Hub & Spoke)

### THE LINK FLOW SYSTEM
Every post feeds authority to the pillar. Pillar feeds it back down.

```
PILLAR POST (3,000+ words)
"Complete Guide: How to Use AI at Work in 2026"
        ↓ internal links to ↓
┌───────────────────────────────────────────┐
│  SUPPORTING POST    SUPPORTING POST       │
│  "AI for emails"    "AI for marketers"   │
│       ↓                    ↓              │
│  MONEY POST         MONEY POST            │
│  "Best AI writing   "Jasper AI review"   │
│   tools 2026"                             │
└───────────────────────────────────────────┘
        ↑ all posts link back UP to pillar ↑
```

### INTERNAL LINKING RULE (Every Post Must Have):
- **1 link UP** → to the pillar post
- **2 links SIDEWAYS** → to related supporting posts  
- **1 link DOWN** → to a money post with affiliate link

### EXTERNAL LINKING RULE (Every Post Must Have):
- **2-3 external links** → to authoritative sources (OpenAI, McKinsey, Forbes, research papers)
- Always open in new tab (`target="_blank"`)
- This signals to Google that you cite credible sources = E-E-A-T boost

## PART 7 — DOFOLLOW VS NOFOLLOW POLICY

### When building backlinks, ALWAYS verify:
- Guest posts → **demand dofollow** (this is the point)
- Directory submissions → usually nofollow (still worth it for traffic)
- Reddit/Quora → nofollow (fine, drives traffic)
- News mentions/HARO → **dofollow** (most valuable)

### How to check if a link is dofollow:
Right-click the link → "Inspect Element" → look for `rel="nofollow"`
If you see `rel="nofollow"` = worthless for DA
If you see nothing or `rel="dofollow"` = counts for DA
