## MONETIZATION STACK (activate in order)

### Phase 1 — Month 1-2: Affiliate Only
- [ ] Apply to Amazon Associates
- [ ] Apply to 2-3 niche-specific affiliate programs
- [ ] Add affiliate links to all "best of" and review posts
- [ ] Add affiliate disclosure to every post

### Phase 2 — Month 3-4: Add Display Ads
- [ ] Apply to Google AdSense (no minimum traffic)
- [ ] Or apply to Ezoic (better RPM, no minimum)
- [ ] Place ads in sidebar, between sections, after content

### Phase 3 — Month 5+: Add Digital Product
- [ ] Create one simple product (checklist, template, ebook)
- [ ] Price: $9-29 (low barrier for first buyers)
- [ ] Sell via Gumroad or Lemon Squeezy (no setup cost)
- [ ] Add link to product in every relevant post
