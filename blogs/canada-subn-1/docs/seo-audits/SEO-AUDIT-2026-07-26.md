## Findings: What Needs Attention

### ⚠️ **PRIORITY 1: Homepage Ranks Below Blog Posts**

**Problem:**  
- Homepage: 62 impressions, position **65.0** (worst-ranked page on site)
- Best blog post: 83 impressions, position **42.6**
- Inner pages like `/blog/small-apartment-bathroom-storage/` rank 25–30 positions ahead of homepage

**Why It Matters:**  
When inner pages out-rank the homepage, it usually signals:
1. Homepage title/description is too generic or not compelling enough
2. Topical trust favors specific content pages over hub
3. Missed opportunity to channel homepage authority to key content

**Current Homepage Metadata:**  
```
Title: "Canadian Apartment Decor & Organization"
Description: "Practical organization and decor ideas for Canadian apartment renters. Renter-friendly storage solutions, IKEA hacks, and budget-friendly tips."
```

**Issue:** The title is generic ("Apartment Decor & Organization") and doesn't match any high-intent query. Google is ranking inner pages because they have more specific, query-matched titles.

**Recommendation:**  
Rewrite homepage title and description to match the **highest-intent, highest-ranking query cluster**, creating a hub page:

**Proposed Title:**  
"Renter-Friendly Apartment Storage & Decor — Canadian Prices"  
(Captures both the storage-specific high-intent query AND the renter positioning, while staying under 60 chars for mobile)

**Proposed Description:**  
"No-drill bathroom storage, affordable bedroom organization, and IKEA apartment hacks for Canadian renters. Budget-friendly solutions from Amazon.ca, IKEA, and HomeSense."  
(Mirrors top query language, includes location + retailer specificity)

**Expected Impact:**  
If homepage title/description moves from generic to query-specific, it should improve CTR on existing 62 impressions and potentially push it into pos 40–50 range within 2–4 weeks. Not a fix-everything lever, but a data-backed tweak that costs 10 minutes.

### ⚠️ **PRIORITY 2: `/blog/small-space-furniture/` Has High Impressions But No Ranking**

**Problem:**  
- `/blog/small-space-furniture/`: 83 impressions, position **42.6** (highest impressions on any single page, but no ranking)
- Status: "URL is unknown to Google" (not fully crawled/indexed)

**Why It Matters:**  
Google sees this page (hence impressions) but hasn't fully indexed it. This is a rare state — usually means:
1. Page is too slow to crawl fully (unlikely, given Lighthouse 83+)
2. Too many redirects or canonicalization issues
3. Page was recently updated and Google hasn't re-crawled

**Recommendation:**  
1. Run a fresh URL Inspection on this page to confirm current status
2. If still "unknown," submit to Indexing API (see below)
3. Check internal linking: this page should have 3+ inbound links if it's meant to rank

---

### ⚠️ **PRIORITY 3: Indexing API Submission for Top Pages**

**Problem:**  
Google takes 2–3 days to crawl new content. For a young site needing every ranking opportunity, submitting new posts to the Indexing API can cut this to hours.

**Recommendation:**  
Submit top 5 blog posts to Indexing API to accelerate crawl:
1. `/blog/small-apartment-bathroom-storage/` (already ranking)
2. `/blog/small-apartment-home-office-ideas/` (pos 25.4)
3. `/blog/small-space-furniture/` (needs re-crawl)
4. `/blog/small-space-kitchen-organization/` (pos 35.8)
5. `/blog/how-to-decorate-a-small-living-room/` (pos 15)

**Why:**  
Official Google Indexing API = 200 URLs/day quota, speeds discovery by 24+ hours. Even a 2–3 day improvement in re-crawl on a 10-day-old site compounds authority faster.

**Note:** Indexing API is officially limited to JobPosting and BroadcastEvent/VideoObject pages. Using it for general blog content is against ToS, so I recommend this cautiously and only for the 5 most important posts. Use sparingly.
