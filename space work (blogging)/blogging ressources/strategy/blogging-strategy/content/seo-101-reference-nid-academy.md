- **On-Page SEO** — title tags, meta descriptions, header tags (H1-H6), content, images,
  internal links. Same definition + best-practices-list pattern throughout.
- **Off-Page SEO** — link building, social media, brand mentions.
- Hero visual: a circular hub-and-spoke "SEO Process" wheel diagram (Website Analysis,
  Reporting, Link Building, Client Requirements, Content Writing, Keyword Research, SEO

## Article 3 — "7 Essential Steps for Perfect SEO Writing (AI)"

Seven-step framework for AI-assisted SEO writing:
1. Keyword research & understanding search intent
2. Compelling, keyword-inclusive headlines
3. Structuring content for readability (subheadings, logical flow, scannability)
4. Quality content balancing SEO with reader value (no keyword stuffing — use
   synonyms/related phrases instead of exact repetition)
5. Meta description optimization (under 160 characters, action-oriented language)
6. Internal + external link implementation (internal links for navigation, external
   backlinks from reputable sources for domain authority)
7. Continuous improvement — treat optimization as iterative, refine using analytics

Other tips: use long-tail keywords for niche targeting; add transition sentences
between sections for flow. This maps closely to the workflow the `blog` skill family
already automates (blog-outline → blog-write → blog-seo-check), useful mainly as a
plain-language checklist version if ever explaining the process to a non-technical
collaborator.

## Article 4 — "How to Set Up Your Own Autoblogging Website"

Covers autoblogging concepts, a 5-step WordPress setup path, and risk/ethics caveats.
**Not directly applicable to this project** — Canada/UK sites are Astro-based static
builds with manually reviewed content per post (per the daily trend-content loop and
one-post-per-day rule in [[project_seo_growth_plan]]), not WordPress RSS-aggregation
autoblogs. Saved for awareness only.

Setup steps described: install WordPress via host → pick an autoblogging-compatible
theme → add plugins (WP RSS Aggregator, WP Content Pilot, Autoblog, CyberSyn, Auto Post
Scheduler mentioned) → configure plugin settings to content/SEO strategy → connect AI
tools for content discovery, generation (NLP), and SEO analysis. Article stresses human
review remains necessary for accuracy, and flags originality/authenticity concerns with
heavy automation — worth remembering given this project's existing "no invented
content" standard (see backlink/content decisions in [[project_seo_growth_plan]]).

## Article 5 — "Generative Engine Optimization (GEO)"

10-section piece framing GEO as the AI-era counterpart to SEO: optimizing content so AI
assistants (ChatGPT, Perplexity, AI Overviews, etc.) cite/synthesize it into answers,
rather than optimizing purely for click-through to the site. Covers GEO vs. SEO
comparison, market trends, benefits, how AI systems select sources, implementation
strategy, a case study, integration with existing SEO, and future outlook.

Three implementation pillars described: content optimization (citations, statistics,
clarity), technical elements (schema markup, site speed), and ongoing experimentation
with content formats. Cited directional stats: adding citations and statistics
meaningfully increases how often AI systems select/surface content, and clear structure
matters a lot — consistent with (not novel next to) what [[project_seo_growth_plan]]
already found in the site-wide blog-geo audit run the same day (2026-08-01): both blogs
score well on structure/schema but weak on Q&A-formatted headings and standalone
citation capsules. Recommends treating GEO as additive to SEO, not a replacement, and
revisiting strategy quarterly given how fast AI search evolves.

**Relevance:** directly reinforces the GEO audit and priority-fix list already produced
for Canada/UK today — no new action needed beyond what's already queued (H2s rephrased
as questions, citation-capsule sentences per section).
