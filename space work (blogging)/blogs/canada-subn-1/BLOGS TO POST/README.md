## How to publish a post

1. Write your blog post and save it here as a `.md` file
2. When ready, copy it into:
   `CANADA SUBN 1\smallspacehome\src\content\blog\`
3. Make sure the file has the correct frontmatter at the top:

```
---
title: "Your Post Title"
description: "Short description (150 chars max)"
image: "/images/your-image.jpg"
datePublished: "2026-01-01"
dateModified: "2026-01-01"
author: "Sarah Mitchell"
tags: ["tag1", "tag2", "tag3"]
featured: false
category: "Organization"
readTime: 7
faqs:
  - q: "Question?"
    a: "Answer."
---
```
