all 32 posts, not just the 22 currently in the pin rotation. Formula per `PINTEREST-SEO.md`:
title keyword-front-loaded (≤100 chars), description 2-3 sentences with the keyword once +

content is identical, so splitting SEO value across duplicate copy isn't worth the extra
writing effort. If you want variant-level differentiation later, that's a follow-up, not
