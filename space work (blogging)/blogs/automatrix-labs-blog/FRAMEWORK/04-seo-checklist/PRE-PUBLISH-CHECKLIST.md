# STEP 04 — Pre-Publish SEO Checklist
> Run this checklist on EVERY post before hitting publish. No exceptions.

---

## CHECKLIST (copy for each post)

**Post title:** ___________________________________
**Target keyword:** ___________________________________
**Date:** ___________________________________

### ON-PAGE SEO
- [ ] Keyword appears in the title (within first 60 characters)
- [ ] Keyword appears in the meta description (within first 150 characters)
- [ ] Keyword appears in the URL slug (short, no stop words)
- [ ] Keyword appears in the first 100 words of the post
- [ ] Keyword appears in at least one H2 heading
- [ ] Keyword appears naturally 3-5x throughout (not stuffed)
- [ ] Related keywords / synonyms used naturally in body

### CONTENT QUALITY
- [ ] Post is at least 1,200 words (1,500+ preferred)
- [ ] Intro hooks the reader and states what they'll learn
- [ ] Content is broken into clear H2 and H3 sections
- [ ] At least one table, list, or visual element included
- [ ] FAQ section with 3+ questions from People Also Ask
- [ ] Conclusion with a clear CTA

### INTERNAL LINKING
- [ ] Links to 2-3 other posts on your blog
- [ ] Anchor text is descriptive (not "click here")
- [ ] No broken internal links

### EXTERNAL LINKING
- [ ] At least 1 link to a reputable external source
- [ ] External links open in a new tab

### IMAGES
- [ ] At least 1 featured image (hero image)
- [ ] All images have descriptive alt text (include keyword where natural)
- [ ] Images are compressed (under 200KB each)
- [ ] Image file names are descriptive (not "image001.jpg")

### TECHNICAL
- [ ] Meta title set (50-60 characters)
- [ ] Meta description set (150-160 characters)
- [ ] URL slug is clean and includes keyword
- [ ] Post is assigned to the correct category
- [ ] Post has 3-5 relevant tags
- [ ] No spelling or grammar errors (run through Grammarly)
- [ ] Post previewed on mobile — looks good?

### MONETIZATION
- [ ] Affiliate links added where relevant (with disclosure)
- [ ] Affiliate links are set to "nofollow" or "sponsored"
- [ ] Disclosure statement at top: "This post contains affiliate links..."
- [ ] CTA is clear at the end of the post

### AFTER PUBLISHING
- [ ] Submit URL to Google Search Console (URL Inspection tool)
- [ ] Share on social media (Twitter/X, Pinterest, Facebook group)
- [ ] Add internal link FROM another related post TO this new post
- [ ] Add to Topic Pipeline tracker with status = 🟢 Published

---

## QUICK REFERENCE — KEY METRICS

| Element | Optimal Length |
|---------|---------------|
| Title tag | 50-60 characters |
| Meta description | 150-160 characters |
| URL slug | 3-5 words, keyword included |
| Post length (regular) | 1,500-2,500 words |
| Post length (pillar) | 3,000-5,000 words |
| Paragraphs | 2-4 lines max |
| Images | 1 per 300-500 words |
