## POST TYPES CHEAT SHEET

| Type | Title Formula | Goal |
|------|-------------|------|
| Pillar | "Complete Guide to [Topic] in 2026" | Authority + traffic |
| How-To | "How to [Do X] Step by Step" | Traffic + trust |
| Listicle | "10 Best [X] for [Y]" | Traffic + affiliates |
| Comparison | "[X] vs [Y]: Which is Better?" | Affiliates |
| Review | "[Product] Review: Is It Worth It?" | Affiliates |
| Case Study | "How I [Result] Using [Method]" | Trust + all income |
| FAQ | "What is [X]? Everything You Need to Know" | Long-tail traffic |
