# STEP 00 — Niche Selection Scorecard
> Score every candidate. Pick the highest scorer. No exceptions.

---

## HOW TO USE
1. List 3-5 niche ideas below
2. Research each one using the checklist
3. Fill the scorecard for each
4. Highest score wins → move to Step 01

---

## RESEARCH CHECKLIST (do this for EACH niche)

### A. Demand Check
- [ ] Go to trends.google.com → search your niche keyword → set to "5 years"
- [ ] Is the trend rising, flat, or declining?
- [ ] Search on Reddit → does a community exist with 10k+ members?
- [ ] Type keyword in Google → count autocomplete suggestions (more = better)

### B. Monetization Check
- [ ] Search "[niche] affiliate program" → found programs? List them:
- [ ] Check Amazon → products with 500+ reviews in this niche?
- [ ] Search "[niche] blog" → do existing blogs show display ads?
- [ ] Any SaaS tools in this niche with recurring commissions?

### C. Competition Check
- [ ] Google your main keyword → who ranks on page 1?
- [ ] Are any Reddit/Quora results on page 1? (good sign = low competition)
- [ ] Are big brands (Forbes, Healthline, etc.) dominating? (bad sign)
- [ ] Check domain authority of top 5 results at moz.com/domain-analysis
