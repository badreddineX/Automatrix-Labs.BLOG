# Ebook Cover Prompt — Creative Design System

> A reusable template for generating standout ebook covers, with creative choices built in.
> Use this to design ANY future ebook — pick a layout archetype, a visual metaphor, a colour cue, and a creative accent, then fill in the master prompt.

**Full path** → `digital prod/COVER-PROMPT-TEMPLATE.md`

---

## The Creative Formula

```
VISUAL METAPHOR (what transformation looks like)
+
LAYOUT ARCHETYPE (how the eye travels)
+
COLOUR CUE (the feeling you trigger)
+
CREATIVE ACCENT (the memorable detail)
+
VALUE COPIES (why it's worth the price)
```

A cover is memorable when one element tells the whole story. **Pick ONE bold idea and do it perfectly** — do not stack five ideas.

## 1. Layout Archetypes (choose 1)

| Archetype | When to use | How it works |
|---|---|---|
| **A. Split Transformation** | Outcome = change (reset, makeover, refresh) | Same scene, two halves: BEFORE (dull, cluttered, flat) vs AFTER (styled, calm, warm). Seamless center line. The brain sees the value instantly |
| **B. Window Reveal** | Outcome = hidden potential | Scene viewed through an arched/round window or open door, showing the transformed space beyond — implies "step into the result" |
| **C. Object Metaphor** | Outcome = abstract (time, money, protection) | One symbolic object carries the idea: an hourglass (time saved), brass shield (deposit protected), stack of coins (cost vs value), measuring tape in a circle (fit) |
| **D. Checklist Cover** | Product = guides, systems | The cover itself looks like the product: a "tick-box" grid with the title at top — instantly says "practical, usable, checklist included" |
| **E. Overlay Stacks** | Product = bundles (kits, toolkits) | Layered dimensional panels floating in perspective (like stacked cards) — each layer a deliverable: SYSTEM / BONUS / BONUS / BONUS. Says "you get more than one thing" |
| **F. Still-Life Wealth** | Product = premium, aspirational | A rich flat-lay of the "ingredients": swatches, tools, textures, ruler, herbs — art-directed like a magazine spread. Says "premium, crafted, credible" |

## 2. Visual Metaphors Menu (choose 1)

Match the metaphor to the transformation the book delivers:

| If your book delivers… | Use this metaphor |
|---|---|
| Time saved | Hourglass, clock face with calm room inside the dial, a single hour arc |
| Deposit / money protected | Brass shield, unbroken egg, coin stack untouched |
| Space created | Expanding measuring tape, doors opening outward, objects floating apart |
| Order from chaos | The divide line of light — chaos on the shadow side, order on the light side |
| Weight lifted | Feather on top of a neatly folded stack |
| Choice made easier | A single path through swatches/cards, one highlighted choice |
| Small → spacious | A small frame/box in the corner, the same room expanding to fill the frame |
| A system you follow | Visible numbered zones on the scene (1, 2, 3, 4) with fine lines |
| Rental safety | A key, a contract without marks, a wall with no nail holes — clean and pristine |
| Transformation | The split scene (before/after) is itself the strongest metaphor |

**Rule:** the metaphor must be *understood in half a second* — if it needs explaining, it's too clever.

## 3. Colour Cue (choose 1 palette per feeling)

| Outcome you promise | Palette | Anchor colour |
|---|---|---|
| Calm & orderly | Warm cream + sage + oat | Cream |
| Warm & cosy | Oat + terracotta + honey | Terracotta |
| Fresh & clean | Soft white + light sage + brass | Sage |
| Premium & curated | Cream + deep forest + brass | Forest |
| Energetic refresh | Warm white + coral + soft teal | Coral |
| Trust & safety | Oat + soft blue-grey + oak | Blue-grey |

**Colour rule:** one dominant + one accent only. Two colours tell a story; five colours shout.

## 4. Creative Accents (add 1 spark)

| Accent | Effect |
|---|---|
| **Polaroid stack** | A corner stack of polaroids showing "process" — builds story & legitimacy |
| **Handwritten arrow/note** | One small hand-sketched circle or arrow on the key object — adds human touch & "method" feeling |
| **Ribbon banner** | A thin cloth ribbon behind the title — feels award-worthy, anchors the eye |
| **Gold foil edge** | A thin gold line framing the title block — premium signal at zero cost |
| **Soft vignette** | Darker edges, light center — draws the eye to the title & scene like a spotlight |
| **Torn edge reveal** | The "after" side torn from the "before" like paper — literal reveal metaphor |
| **Number badge** | A circular badge: "12 METHODS" / "£150 LIST" — makes the number the hero |
| **Painted texture** | Warm plaster/linen texture background where cream space should be — gallery feel |
| **Brass object hook** | A ring/line that visually "hangs" the title — ties to no-damage & design |
| **Scene within a shape** | The scene cropped inside a circle or arch (mirror/arch motif) — ties to interior design |

## 5. Typography & Texture Directives

- **Titles:** elegant serif (Playfair Display style) — large, wide letterspacing, warm white or deep forest
- **Body/benefits:** clean light sans (Inter style) — small, precise, with tick marks
- **Kicker:** small caps, letterspaced, brand color
- **Texture:** warm plaster, linen weave, or fine paper grain in the cream areas — kills the "flat digital" look
- **Depth:** a 5% soft shadow under the title block and badges → physically present feel
- **Finish:** two micro-details per cover max — a thin gold line + a soft vignette, for example

## 7. Creative Ideas by Niche (ready-made combos)

### Organization / Storage book
- Archetype: **Split Transformation** + Metaphor: *chaos → light divide* + Accent: *number badge "4 ZONES"*
- Scene: the same corner — left shadowed with clutter, right sunlit and styled, a single line of light tracing the divide
- Anchor: "PRO ORGANIZERS $50–100/HR → THIS $9"

### Makeover / Refresh book
- Archetype: **Split Transformation** (seasonal or before/after) + Accent: *torn-edge reveal*
- Scene: sofa and table identical in both halves; props change per season/mood
- Anchor: "DESIGNER £500+ → THIS £7"

### No-damage / rental-protection book
- Archetype: **Window Reveal** + Metaphor: *wall with no nail holes* + Accent: *brass object hook*
- Scene: an arched mirror frame reveals the styled gallery wall behind; wall surface pristine
- Anchor: "DAMAGE DEDUCTION $385+ → THIS $9"

### Budget book
- Archetype: **Object Metaphor** + Metaphor: *coin stack* + Accent: *handwritten arrow pointing at the small stack*
- Scene: a styled upgraded corner beside a small pile of coins — upgrade costs less than the coins
- Anchor: "KITCHEN QUOTES £2,000+ → THIS UNDER £100"

### Colour / design guide
- Archetype: **Still-Life Wealth** + Metaphor: *single path through swatches* + Accent: *gold foil edge*
- Scene: fan of swatches, one highlighted with a small brass marker, grey-British window light
- Anchor: "TESTER-POT TRIAL & ERROR £50+ → THIS £12"

### Printable art / bundle
- Archetype: **Overlay Stacks** + Accent: *number badge "12 × 5 SIZES"*
- Scene: dimensional floating panels showing a frame, sizes, layout guide
- Anchor: "ONE FRAMED PRINT £30+ → A FULL WALL £8"

### First-week / move-in book
- Archetype: **Window Reveal** (doorway) + Metaphor: *boxes → settled* + Accent: *polaroid stack*
- Scene: open doorway revealing a fully settled bright room; a stack of polaroids shows unpacking progress
- Anchor: "UNPLANNED MOVES COST 20+ HOURS → THIS $9"

## 8. Before You Generate — 30-Second Checks

- [ ] ONE bold idea picked (metaphor + accent), not five
- [ ] The promise is visible in the scene WITHOUT reading the title
- [ ] Two colours max + one accent detail
- [ ] Benefit lines carry real numbers (12 methods, £150, 60 min, 5 sizes)
- [ ] Anchor compares to the expensive alternative
- [ ] Back cover has value stack + proof + guarantee + URL
- [ ] Title readable at thumbnail size (200×200px test)
- [ ] 1600×1600px, 1:1, 300 DPI PNG for print
- [ ] Same treatment across your whole product line for a coherent shelf
